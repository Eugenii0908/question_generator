# Генератор учебных вопросов (LLM Question Generator)

Учебный проект, представляющий собой Fullstack-приложение для автоматической генерации вопросов и ответов по предоставленному тексту с использованием локальной языковой модели (LLM). 

Приложение построено на микросервисной архитектуре и полностью упаковано в Docker.

## 🚀 Основные возможности
*   **Генерация вопросов:** Создание от 1 до 15 вопросов с ответами по любому учебному тексту.
*   **Загрузка файлов:** Поддержка автоматического извлечения текста из файлов форматов `.pdf` и `.docx`.
*   **Валидация данных:** Строгая проверка вводимых данных (длина текста, количество вопросов) с понятными сообщениями об ошибках.
*   **История:** Сохранение сгенерированных наборов в базу данных с возможностью просмотра полной информации и удаления.
*   **Современный интерфейс:** Адаптивный дизайн с темной темой, модальными окнами и статусами загрузки.

## 🏗 Архитектура проекта
Проект состоит из трех основных компонентов (контейнеров):
1.  **`main_service` (Основной сервис):** Написан на FastAPI. Принимает запросы от клиента, управляет базой данных (SQLite через SQLAlchemy), обрабатывает файлы (PDF/DOCX) и выступает посредником для LLM.
2.  **`llm_service` (Сервис LLM):** Написан на FastAPI. Принимает текст, формирует промпт и отправляет запрос в локальную нейросеть через Ollama API.
3.  **`Ollama` (Локальная LLM):** Работает на хост-машине (вне Docker). Используется модель `qwen3.5:4b` (или любая другая совместимая).

## 🛠 Стек технологий
*   **Backend:** Python 3.12, FastAPI, Uvicorn, Pydantic (валидация), SQLAlchemy (ORM).
*   **База данных:** SQLite (файл `requests.db`).
*   **Парсинг файлов:** `pypdf`, `python-docx`.
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API).
*   **LLM:** Ollama (модель Qwen 3.5).
*   **Инфраструктура:** Docker, Docker Compose.

## 📦 Установка и запуск (Docker)

Для запуска вам понадобятся установленные **Docker Desktop** и **Ollama**.

### 1. Подготовка нейросети
Убедитесь, что Ollama запущена, и скачайте модель (если еще не сделали этого). Откройте терминал и выполните:
```bash
ollama run qwen3.5:4b
```
*(Модель должна работать в фоне на порту `11434`)*.

### 2. Запуск приложения
Клонируйте репозиторий и перейдите в папку с проектом. Убедитесь, что в корне лежит файл `docker-compose.yml`.

Выполните команду:
```bash
docker compose up --build -d
```
*(Флаг `-d` запустит контейнеры в фоновом режиме. Если хотите видеть логи, запускайте без него).*

### 3. Доступ к приложению
После успешной сборки откройте браузер:
*   **Web-интерфейс:** [http://localhost:8000](http://localhost:8000)
*   **Swagger UI (Документация API Основного сервиса):** [http://localhost:8000/docs](http://localhost:8000/docs)
*   **Swagger UI (Документация LLM сервиса):** [http://localhost:8001/docs](http://localhost:8001/docs)

## 💻 Локальный запуск (Без Docker)

Если вы хотите запустить проект без контейнеров:

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows:
   .\venv\Scripts\activate
   # Linux/Mac:
   source venv/bin/activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r DB/requirements_DB.txt
   pip install -r LLM/requirements_LLM.txt
   ```
3. Запустите сервис LLM (в отдельном терминале):
   ```bash
   cd LLM
   uvicorn llm_service:app --port 8001
   ```
4. Запустите Основной сервис (в другом терминале):
   ```bash
   cd DB
   uvicorn main:app --port 8000
   ```

## ⚠️ Возможные проблемы

*   **Ошибка `Connection refused` при генерации:** Убедитесь, что Ollama запущена и модель `qwen3.5:4b` скачана.
*   **Не читаются PDF-файлы:** Если PDF состоит только из картинок (сканов), библиотека `pypdf` не сможет извлечь текст. Для таких файлов требуется OCR (например, Tesseract).
*   **Ошибка `exec: "uvicorn": executable file not found`:** Убедитесь, что при сборке Docker-образа выполнилась команда установки зависимостей (проверьте содержимое `requirements_DB.txt`, `requirements_LLM.txt`).
*   **Не грузится история / ошибка 500 в консоли:** Проверьте, что папка `data/` существует и в ней есть права на запись (Docker Volume).
